# Q4: How have nonstop routes changed since 2015?

**Research question:** How have nonstop routes changed since 2015, and which airports gained or lost the most destinations?

The main chart compares one number for each airport, how many nonstop destinations it serves, in 2015 and in a later year you pick. It ranks the change, so the biggest gainers and losers stand out.

<div class="note" label="Definitions">

- **Route:** one direction of travel between two airports. Nashville to Denver and Denver to Nashville are two routes.
- **Active route:** at least 52 performed departures in the year (about one a week on average). This drops one-off and charter flights. It does not prove the route ran every week.
- **Nonstop destinations:** the number of different airports an airport has an active route to.
- **Source:** BTS T-100 Domestic Segment, scheduled passenger service (Class F), 2015-2025.

</div>

```js
const nat = national.find((d) => d.year === year);
const base = national.find((d) => d.year === 2015);
const inYear = airports.filter((d) => d.year === year);
const ids2015 = new Set(airports.filter((d) => d.year === 2015).map((d) => d.airport_id));
const idsYear = new Set(inYear.map((d) => d.airport_id));
const comparable = inYear.filter((d) => ids2015.has(d.airport_id));
const newAirports = inYear.filter((d) => !ids2015.has(d.airport_id))
  .sort((a, b) => d3.descending(a.nonstop_destinations, b.nonstop_destinations));
const goneAirports = airports.filter((d) => d.year === 2015 && !idsYear.has(d.airport_id))
  .sort((a, b) => d3.descending(a.nonstop_destinations, b.nonstop_destinations));
// Ties are broken by the 2015 count (larger airports first), so the ranking is stable.
const gainers = comparable.filter((d) => d.change_from_2015 > 0)
  .sort((a, b) => d3.descending(a.change_from_2015, b.change_from_2015) || d3.descending(a.destinations_2015, b.destinations_2015))
  .slice(0, topN);
const losers = comparable.filter((d) => d.change_from_2015 < 0)
  .sort((a, b) => d3.ascending(a.change_from_2015, b.change_from_2015) || d3.descending(a.destinations_2015, b.destinations_2015))
  .slice(0, topN)
  .reverse();
```

<p class="viz-note">Each bar is one airport's change in active nonstop destinations; the label gives the change and the two counts (2015 to ${year}). Only airports with an active route in both years are ranked; airports that started or stopped service are listed below instead of being counted as a change from or to zero. Hover a row for the percent change.</p>

## What does this visualization show?

- **The network got wider.** There were 23% more active routes in 2025 than in 2015 (7,773 vs. 6,324).
- **2020 cut flights, not routes.** Routes fell only 6% in 2020, while Q2 shows passengers fell by more than half. By 2021 there were more routes than in 2019.
- **Growth was strongest in the South and Southwest.** Nashville doubled its destinations (49 to 101). Sarasota, Denver, Phoenix and Dallas/Fort Worth follow.
- **Losses were small.** The largest was Detroit, 12 fewer destinations. Most losers are small airports that lost a few routes.

These are counts of routes, not of seats or flights: an airport can add destinations while flying each one less often. Q7 puts route counts next to seat capacity.

## How the data was prepared

`pipeline/prep_q4_q5.py` builds both tables from the notebook's route table (`q4_routes.csv`: performed departures per year, origin and destination, Class F): it keeps routes with at least 52 departures, counts distinct destinations per origin airport and year, and attaches the 2015 count. The notebook's Q4 cell uses the same 52-departure rule; the Milestone 2 version counted a route with a single departure (see `pipeline/README.md`).
