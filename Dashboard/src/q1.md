# Q1: Airport and Carrier Rankings

**Research question:** Which US domestic airports and carriers move the most passengers, freight, mail, and estimated payload, and how do their rankings differ?

This page compares **US domestic departing traffic**. Rankings are national for the selected year, not just among the items selected for the chart. The Top 5 tables identify leaders; the bump chart compares the same selected airports or carriers across four measurements.

<div class="q1-definition">

**Definitions and source**

- **Passenger segments:** Passengers transported on individual nonstop flight segments. A connecting traveler can contribute to multiple segment counts.
- **Freight:** Transported air cargo excluding passenger baggage, reported in pounds.
- **Mail:** Transported mail weight, reported in pounds.
- **Estimated payload carried:** `200 × passengers + freight_lb + mail_lb`, in pounds. This is a weight estimate for transported traffic, **not** the aircraft's available payload capacity.
- **National rank:** Position among all airports or carriers in the processed dataset for the selected year and metric. Rank 1 is highest. Nonpositive measurements are not plotted; ties follow the precomputed ranks.
- **Data source:** [BTS T-100 Domestic Segment](https://www.transtats.bts.gov/DatabaseInfo.asp?QO_VQ=EED), US carriers, 2015–2025. This page includes the service classes represented in the supplied `all_classes` aggregations, rather than restricting to scheduled passenger service.
- **200 lb assumption:** [14 CFR § 291.45](https://www.law.cornell.edu/cfr/text/14/291.45) defines the federal T-100 passenger ton-mile calculation using **200 lb per passenger including baggage**, across operations and service classes. We use the same standard weight as a simplified estimate here; individual flight weights were not measured.

</div>

```js
import * as d3 from "npm:d3";

const airports = await FileAttachment("./data/q1_airports_year_all_classes.csv")
  .csv({typed: true});

// Annual carrier totals and national rankings from the supplied data.
const carriers = await FileAttachment("./data/q1_carriers_year.csv")
  .csv({typed: true});

const measures = [
  {rank: "passengers_rank", value: "passengers", label: "Passengers", unit: "passenger segments"},
  {rank: "freight_lb_rank", value: "freight_lb", label: "Freight", unit: "lb"},
  {rank: "mail_lb_rank", value: "mail_lb", label: "Mail", unit: "lb"},
  {rank: "estimated_payload_carried_lb_rank", value: "estimated_payload_carried_lb", label: "Estimated payload", unit: "lb"}
];

const airportSelection = Mutable(["ATL", "LAX", "MEM"]);
const carrierSelection = Mutable(["WN", "FX", "5X"]);

// Mutable setters belong in the declaring code block.
function setAirportSelection(codes) {
  airportSelection.value = codes;
}
function setCarrierSelection(codes) {
  carrierSelection.value = codes;
}

const colors = d3.schemeTableau10;
const symbols = [d3.symbolCircle, d3.symbolSquare, d3.symbolTriangle, d3.symbolDiamond, d3.symbolCross];
const number = d3.format(",.0f");

function entityInfo(data, key, labelKey) {
  return Array.from(
    d3.group(data.filter(d => d[key]), d => String(d[key])),
    ([code, rows]) => ({
      code,
      name: rows.find(d => d[labelKey])?.[labelKey] ?? code,
      city: rows.find(d => d.city)?.city ?? "",
      state: rows.find(d => d.state)?.state ?? ""
    })
  ).sort((a, b) => d3.ascending(a.code, b.code));
}

const airportInfo = entityInfo(airports, "airport", "city");
const carrierInfo = entityInfo(carriers, "carrier_code", "carrier_code");

function topFive(rows, measure) {
  return rows
    .filter(d => Number.isFinite(+d[measure.rank]) && +d[measure.rank] > 0 && +d[measure.value] > 0)
    .slice()
    .sort((a, b) => +a[measure.rank] - +b[measure.rank])
    .slice(0, 5);
}
```

```js
const isAirport = mode === "airport";
const data = isAirport ? airports : carriers;
const info = isAirport ? airportInfo : carrierInfo;
const key = isAirport ? "airport" : "carrier_code";
const selection = isAirport ? airportSelection : carrierSelection;
const validCodes = new Set(info.map(d => d.code));
const chosen = selection.filter(code => validCodes.has(code));
const yearData = data.filter(d => +d.year === +year);
const nameByCode = new Map(info.map(d => [d.code, d.name]));

function addItem(code) {
  if (!validCodes.has(code) || chosen.includes(code) || chosen.length >= 5) return;
  if (isAirport) setAirportSelection([...chosen, code]);
  else setCarrierSelection([...chosen, code]);
}

function removeItem(code) {
  const next = chosen.filter(d => d !== code);
  if (isAirport) setAirportSelection(next);
  else setCarrierSelection(next);
}
```

## Ranking comparison

**What this chart compares:** The national ranks of selected ${isAirport ? "airports" : "carriers"} across passenger traffic, freight, mail, and estimated payload in **${year}**. The horizontal axis represents **traffic types, not years**. Rank 1 is highest. Different marker shapes help distinguish lines without relying only on color.

```js
{
  const rows = yearData.filter(d => chosen.includes(String(d[key])));
  const width = 1050;
  const height = 480;
  const margin = {top: 50, right: 110, bottom: 90, left: 80};

  const x = d3.scalePoint()
    .domain(measures.map(m => m.label))
    .range([margin.left, width - margin.right]);

  const ranks = rows.flatMap(d => measures.map(m => +d[m.rank]))
    .filter(v => Number.isFinite(v) && v > 0);
  const maxRank = Math.max(10, d3.max(ranks) ?? 10);

  const y = d3.scaleLinear()
    .domain([1, maxRank])
    .range([margin.top, height - margin.bottom]);

  const color = d3.scaleOrdinal().domain(chosen).range(colors);
  const chart = document.createElement("div");
  chart.className = "q1-plot";

  const tooltip = document.createElement("div");
  tooltip.className = "q1-tooltip";

  function moveTooltip(event) {
    const box = chart.getBoundingClientRect();
    const left = event.clientX - box.left + 14;
    const top = event.clientY - box.top - tooltip.offsetHeight - 12;
    tooltip.style.left = `${Math.max(0, Math.min(left, box.width - tooltip.offsetWidth))}px`;
    tooltip.style.top = `${Math.max(0, top)}px`;
  }

  function showTooltip(event, row, point) {
    tooltip.replaceChildren();
    for (const [index, label] of [
      `${row[key]} · ${nameByCode.get(String(row[key])) || row[key]}`,
      `Year: ${year}`,
      `Measure: ${point.label}`,
      `National rank: #${point.rank}`,
      `Value: ${number(point.value)} ${point.unit}`
    ].entries()) {
      const line = document.createElement(index === 0 ? "strong" : "div");
      line.textContent = label;
      tooltip.append(line);
    }
    tooltip.style.display = "block";
    moveTooltip(event);
  }

  const svg = d3.create("svg")
    .attr("viewBox", `0 0 ${width} ${height}`)
    .attr("role", "img")
    .attr("aria-label", `${isAirport ? "Airport" : "Carrier"} national rank comparison for ${year}`);

  svg.append("g")
    .attr("transform", `translate(0,${height - margin.bottom})`)
    .call(d3.axisBottom(x));

  svg.append("g")
    .attr("transform", `translate(${margin.left},0)`)
    .call(d3.axisLeft(y).ticks(Math.min(12, maxRank)).tickFormat(d3.format("d")));

  svg.append("g")
    .selectAll("line")
    .data(d3.range(1, maxRank + 1, Math.max(1, Math.ceil(maxRank / 12))))
    .join("line")
    .attr("x1", margin.left)
    .attr("x2", width - margin.right)
    .attr("y1", d => y(d))
    .attr("y2", d => y(d))
    .attr("stroke", "currentColor")
    .attr("stroke-opacity", 0.12)
    .attr("stroke-dasharray", "3 4");

  const line = d3.line()
    .defined(d => Number.isFinite(d.rank) && d.rank > 0)
    .x(d => x(d.label))
    .y(d => y(d.rank));

  for (const [index, code] of chosen.entries()) {
    const row = rows.find(d => String(d[key]) === code);
    if (!row) continue;

    const points = measures.map(m => ({
      label: m.label,
      rank: +row[m.rank],
      value: +row[m.value],
      unit: m.unit
    }));

    const shape = d3.symbol().type(symbols[index % symbols.length]).size(110);
    const lineColor = color(code);

    const path = svg.append("path")
      .datum(points)
      .attr("d", line)
      .attr("fill", "none")
      .attr("stroke", lineColor)
      .attr("stroke-width", 3);

    svg.append("g")
      .selectAll("path")
      .data(points.filter(p => Number.isFinite(p.rank) && p.rank > 0))
      .join("path")
      .attr("d", shape)
      .attr("transform", p => `translate(${x(p.label)},${y(p.rank)})`)
      .attr("fill", lineColor)
      .attr("stroke", "white")
      .attr("stroke-width", 1.5)
      .style("cursor", "crosshair")
      .on("pointerenter", (event, point) => {
        path.attr("stroke-width", 5);
        showTooltip(event, row, point);
      })
      .on("pointermove", moveTooltip)
      .on("pointerleave", () => {
        path.attr("stroke-width", 3);
        tooltip.style.display = "none";
      });

    const last = [...points].reverse().find(p => Number.isFinite(p.rank) && p.rank > 0);
    if (last) {
      svg.append("text")
        .attr("x", x(last.label) + 12)
        .attr("y", y(last.rank) + 4)
        .attr("fill", lineColor)
        .attr("font-size", 13)
        .attr("font-weight", 700)
        .text(code);
    }
  }

  const legend = svg.append("g")
    .attr("transform", `translate(${margin.left},${height - 26})`);

  chosen.forEach((code, i) => {
    const item = legend.append("g").attr("transform", `translate(${i * 160},0)`);
    item.append("path")
      .attr("d", d3.symbol().type(symbols[i % symbols.length]).size(100)())
      .attr("fill", color(code));
    item.append("text")
      .attr("x", 12)
      .attr("y", 4)
      .attr("font-size", 12)
      .attr("fill", "currentColor")
      .text(code);
  });

  if (!rows.length) {
    svg.append("text")
      .attr("x", width / 2)
      .attr("y", height / 2)
      .attr("text-anchor", "middle")
      .attr("fill", "currentColor")
      .text(isAirport
        ? "Select airports to see their ranks."
        : "Select carriers to see their ranks.");
  }

  chart.append(svg.node(), tooltip);
  display(chart);
}
```

## What does this visualization show?

The following observations use the uploaded **carrier** dataset. They compare 2015 with 2025 and do not depend on which carriers are currently selected in the chart.

- **Passenger leader:** WN ranked first in 2015 (147.8 million passenger segments) and 2025 (165.8 million), an increase of approximately **12.2%**.
- **Freight leader:** FX ranked first in both years, but its transported freight decreased from **11.44 billion lb** to **7.94 billion lb**, approximately **30.5% lower**.
- **Mail leader changed:** UA ranked first in 2015 (**274.1 million lb**), while 5X ranked first in 2025 (**1.97 billion lb**).
- **Estimated payload leader:** WN ranked first in both years (**29.89 billion lb** in 2015 and **33.40 billion lb** in 2025). This measure is affected by the 200 lb passenger assumption.

These results demonstrate that passenger, freight and mail leadership do **not** necessarily belong to the same carriers. Codes are retained because the supplied carrier file does not include full carrier names.

**Airport findings from the uploaded airport dataset:**

- **Atlanta leads passenger traffic.** ATL ranked **#1 every year from 2015 through 2025**. It carried **44.34 million departing passenger segments in 2015** and **44.26 million in 2025**, nearly unchanged overall. However, its passenger count dropped from **47.63 million in 2019** to **19.11 million in 2020**.
- **Freight leadership shifted in 2025.** MEM was the #1 freight airport from **2015 through 2024**. In **2025, ANC moved to #1** with **3.06 billion lb**, ahead of MEM (**2.83 billion lb**) and SDF (**2.80 billion lb**). ANC's freight volume rose from **1.33 billion lb in 2015**.
- **Passenger and freight rankings reveal specialization.** In 2025, ATL ranked **#1 for passengers but #21 for freight**, while ANC ranked **#1 for freight but #59 for passengers**. MEM ranked **#2 for freight but #66 for passengers**.
- **Mail leaders changed over time.** ANC ranked #1 for mail in **2015 and 2016**, LAX led in **2019**, and SDF led in **2020–2025**. In 2025, SDF transported **758.16 million lb of mail**. This unusually large reported value should be interpreted as recorded in the source data rather than assumed to represent a general trend.
- **Estimated payload usually follows the passenger leader.** ATL held the #1 estimated-payload rank in every year **except 2020**, when MEM took #1 (**4.87 billion lb**) and ATL ranked #2 (**4.22 billion lb**). ATL regained #1 in 2021 and remained there through 2025. This reflects the formula's combination of passenger weight and cargo volumes.

These observations describe **departing domestic traffic in the supplied dataset**, not airport-wide international operations or total unique travelers.

## How the data was prepared

The project uses **BTS T-100 Domestic Segment** data for US carriers, 2015–2025. The processed airport file groups transported traffic by **departure airport and year**; the carrier file groups transported traffic by **carrier and year**. They include all service classes represented by the supplied input tables.

The four values retained are passengers, freight in pounds, mail in pounds, and estimated payload in pounds. Estimated payload is calculated as:

```tex
\text{Estimated payload (lb)} = 200 \times \text{passengers} + \text{freight (lb)} + \text{mail (lb)}
```

National ranks are **precomputed for each year and measure** across the full corresponding dataset. The selected airports or carriers do not determine the ranking population. Nonpositive measurements are excluded from plotted ranks. The exact tie-ranking rule should be checked against the preprocessing notebook before submission.
