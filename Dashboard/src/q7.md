# Q7: Where do capacity and connectivity indicators suggest a potential mismatch?

Airports with more nonstop destinations usually have more seats. This page looks for airports that break that pattern: many seats on few routes, or few seats spread over many routes. These airports are worth a closer look. The chart alone does not show unmet demand or a missing route.

<div class="note" label="Definitions">

- **Available departing seats:** seats on scheduled passenger flights leaving the airport in the year (BTS T-100, Class F).
- **Active nonstop destinations:** the same measure as Q4. A route counts when it had at least 52 performed departures in the year, so both pages give the same number (for example, Atlanta has 158 in 2025). An airport whose routes all stayed under 52 departures has 0.
- **Average arrival delay:** minutes late for flights arriving at the airport, with early arrivals counted as negative. Same on-time data as Q6 (BTS Reporting Carrier On-Time Performance, larger airlines only). A year is shown only when it has data for all 12 months. Before 2018 a different set of airlines reported (the threshold changed in 2018, which is why Q6 starts in 2018), so 2015-2017 are shown for context and shaded.

</div>

## 1. Airport capacity versus connectivity

Each dot is one airport. Both axes use a log scale, so small and large airports fit on one chart. The dashed line shows how many seats an airport with a given number of destinations usually has, fitted to every U.S. airport in the selected year. Dots far above the line (orange) have more seats than usual for their number of destinations; dots far below it (teal) have fewer. "Far" means more than 1.5 standard deviations from the line.

The state filter only changes which dots are shown. The line is always fitted to the whole country. Click a dot to see that airport's delay history in chart 2.

```js
const nationalModelRows = rows.filter(d => d.year === year && d.seats > 0 && d.destinations > 0 &&
  Number.isFinite(d.seats) && Number.isFinite(d.destinations));

// Fit log(seats) = intercept + slope * log(destinations) by ordinary least squares.
// The regression is an explicit exploratory model, not a causal explanation.
const pairs = nationalModelRows.map(d => ({x: Math.log(d.destinations), y: Math.log(d.seats)}));
const meanX = d3.mean(pairs, d=>d.x);
const meanY = d3.mean(pairs, d=>d.y);
const sxx = d3.sum(pairs, d=>(d.x-meanX)**2);
const sxy = d3.sum(pairs, d=>(d.x-meanX)*(d.y-meanY));
const fitIsValid = pairs.length >= 30 && sxx > 0;
const slope = fitIsValid ? sxy / sxx : NaN;
const intercept = fitIsValid ? meanY - slope*meanX : NaN;
const modelResiduals = fitIsValid ? pairs.map(p=>p.y-(intercept+slope*p.x)) : [];
const residualSD = fitIsValid && pairs.length > 2
  ? Math.sqrt(d3.sum(modelResiduals, r=>r*r)/(pairs.length-2)) : NaN;
const modelReady = fitIsValid && Number.isFinite(residualSD) && residualSD > 0;
const predictSeats = dest => modelReady && dest > 0 ? Math.exp(intercept+slope*Math.log(dest)) : NaN;
const classify = d => {
  const predicted = predictSeats(d.destinations);
  if (!Number.isFinite(predicted) || d.seats <= 0) return {...d, predicted:NaN, logResidual:NaN, z:NaN, className:"Unavailable"};
  const logResidual = Math.log(d.seats / predicted);
  const z = logResidual/residualSD;
  return {...d,predicted,logResidual,z,className:z>=1.5?"Higher than reference":z<=-1.5?"Lower than reference":"Typical"};
};
const classified = scatterData.map(classify);
const visiblePoints = classified.filter(d => mismatchMode === "All airports" || d.className === mismatchMode);
const classColor = {"Higher than reference":"#c2410c","Lower than reference":"#0e7490","Typical":"#64748b","Unavailable":"#94a3b8"};
```

## What does this visualization show?

- **The big hubs fit the pattern.** In 2025, all 72 large and medium hubs sit close to the line: they have about as many seats as their number of destinations predicts.
- **Orange airports are mid-size airports with very few routes.** Hilo has 933,000 seats but only 2 active destinations; Corpus Christi, Fayetteville (NC) and Jacksonville/Camp Lejeune (NC) are similar. All their seats go to two or three airports. These are the airports worth checking for a missing nonstop route.
- **Teal airports are mostly in Alaska** (47 of 54). Bethel, for example, reaches 39 destinations with small planes. That is how remote towns are served, not a sign of unmet demand.
- **Delays grew almost everywhere.** At 67 of the 72 hubs, flights arrived later on average in 2025 than in 2019 (median 8.0 minutes late vs. 4.2). In 2020, with few flights, they arrived early on average. This matches Q6.

An unusual dot is a lead, not proof. Seats and destinations both grow with airport size, and an airport can have few routes because its market is small or because one hub serves it well. Flight frequency, aircraft size and local demand would need a closer look.

## How the data was prepared

- **Seats:** available departing seats on scheduled passenger flights (BTS T-100, Class F), from the processing notebook.
- **Destinations:** the Q4 count (routes with at least 52 performed departures in the year), taken from the notebook's Q4 cell.
- **Delays:** the on-time data from Q6, grouped by the airport where flights arrived. A year needs data in all 12 months; years without it are gaps, not zero. The findings compare 2019 with 2025, both after the 2018 reporting change.
- **Years:** the capacity chart covers 2015-2025, because seats and routes come from T-100, which the 2018 change does not affect. The delay chart also shows 2015-2017 for context, shaded.
- **The line:** a straight-line fit of log(seats) on log(destinations) over every airport with seats and at least one active destination in the selected year. An airport is marked when it is more than 1.5 standard deviations above or below the line.
- The table is `src/data/q7_airport_year_exploratory.csv`, made by the Q7 cell of the processing notebook (`pipeline/refresh_notebook_tables.py` re-runs that cell). State names come from `src/data/q2_airport_year_F.csv`. All chart code is in this page's JavaScript blocks.
