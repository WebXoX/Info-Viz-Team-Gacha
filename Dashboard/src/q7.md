# Q7: Where do capacity and connectivity indicators suggest a potential mismatch?

We compare **available departing seats** with **active nonstop destinations** at US domestic airports. The goal is to identify airports worth investigating, **not** to claim that a difference proves unmet demand or an opportunity for new routes.

> **Data check:** Q7 inherits its nonstop-destination counts from Q4. Before treating the results as final, regenerate both using the agreed minimum of **52 performed departures per directional route per calendar year**. The charts below visualize the CSV as supplied; they do not recalculate routes.

## 1. Airport capacity versus connectivity

Each dot represents one airport. The **reference curve** is a national, year-specific log-log regression of available seats against active nonstop destinations. Atypical airports are flagged when the magnitude of their log residual is at least **1.5 residual standard deviations**. This is an exploratory definition, not evidence of an underserved route or market.

The model uses all airports in the selected year with **positive** seats and destinations, regardless of the state filter. The state filter changes which points are displayed, but never refits the national reference curve. Click a dot to see that airport's arrival-delay history.

```js
const nationalModelRows = rows.filter(d => d.year === year && d.seats > 0 && d.destinations > 0 &&
  Number.isFinite(d.seats) && Number.isFinite(d.destinations));

// Fit log(seats) = intercept + slope * log(destinations) by ordinary least squares.
// The regression is an explicit exploratory model, not a causal explanation.
const pairs = nationalModelRows.map(d => ({x: Math.log(d.destinations), y: Math.log(d.seats)}));
const meanX = d3.mean(pairs, d=>d.x);
const meanY = d3.mean(pairs, d=>d.y);
const sxx = d3.sum(pairs, d=>(d.x-meanX)**2);
const sxy = d3.sum(pairs, d=>(d.x-meanX)*(d.y-meanY));
const fitIsValid = pairs.length >= 30 && sxx > 0;
const slope = fitIsValid ? sxy / sxx : NaN;
const intercept = fitIsValid ? meanY - slope*meanX : NaN;
const modelResiduals = fitIsValid ? pairs.map(p=>p.y-(intercept+slope*p.x)) : [];
const residualSD = fitIsValid && pairs.length > 2
  ? Math.sqrt(d3.sum(modelResiduals, r=>r*r)/(pairs.length-2)) : NaN;
const modelReady = fitIsValid && Number.isFinite(residualSD) && residualSD > 0;
const predictSeats = dest => modelReady && dest > 0 ? Math.exp(intercept+slope*Math.log(dest)) : NaN;
const classify = d => {
  const predicted = predictSeats(d.destinations);
  if (!Number.isFinite(predicted) || d.seats <= 0) return {...d, predicted:NaN, logResidual:NaN, z:NaN, className:"Unavailable"};
  const logResidual = Math.log(d.seats / predicted);
  const z = logResidual/residualSD;
  return {...d,predicted,logResidual,z,className:z>=1.5?"Higher than reference":z<=-1.5?"Lower than reference":"Typical"};
};
const classified = scatterData.map(classify);
const visiblePoints = classified.filter(d => mismatchMode === "All airports" || d.className === mismatchMode);
const classColor = {"Higher than reference":"#c2410c","Lower than reference":"#0e7490","Typical":"#64748b","Unavailable":"#94a3b8"};
```

### Interpretation

The orange and teal points are **statistical outliers relative to the national year-specific reference**, not necessarily airports with service deficiencies. Compare airports with similar destinations and examine their departure frequency, aircraft size and network structure before making decisions.

Airports with similar numbers of nonstop destinations may have very different available seat counts. This can reflect differences in frequency, aircraft size, or route mix. The scatterplot alone **cannot establish** an undersupplied market. Arrival-delay trends provide additional operational context, only for years with valid data.

### Methodology and limitations

- **Capacity:** Available departing seats from T-100 scheduled passenger service (Class F).
- **Connectivity:** Distinct destinations reached by active directional routes, subject to the Q4 minimum of 52 performed departures in a year; reprocess Q4 and Q7 together if the existing CSV uses the old threshold.
- **Linkage:** The processing notebook joins seats/passengers and destination counts by `year` and `airport_id`.
- **Delays:** On-Time data have incomplete coverage. Display missing or unmatched airport-years as unavailable, never as zero. Confirm the delay column and coverage rules against the corrected notebook before interpreting the trend.
- **Mismatch definition:** Fit `ln(seats) = a + b × ln(destinations)` to airports with positive seat/destination counts in the selected year. Flag standardized log residuals ≥ +1.5 or ≤ −1.5 using residual SD = √(SSE / (n−2)). This is an exploratory threshold, not statistical proof of unmet demand. State filtering does not change the fitted national reference.
- **Comparison scope:** Seat count and destination count both reflect airport scale. Even after adjustment, an unusual residual is a lead for further investigation, not a demonstrated service gap.
