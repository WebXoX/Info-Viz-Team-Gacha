# Q2: Domestic Passenger Traffic and Capacity Recovery

**Research question:** How has US domestic scheduled passenger traffic and capacity changed from 2015 to 2025, and how did states and airports recover relative to 2019?

The first chart compares national passengers, available seats, and performed departures. The next chart tracks the recovery of selected states or airports. The final chart shows their share of national passenger traffic in a chosen year.

<div class="note" label="Definitions">

- **Passenger segments:** passengers carried on domestic flight segments, not unique travelers.
- **Available seats:** seats available on performed passenger flight segments.
- **Performed departures:** departures that actually took place, not scheduled-but-cancelled flights.
- **Recovery index:** `100 × current-year traffic ÷ 2019 traffic`. A value of 100 matches 2019; 120 means 20% above 2019.
- **National passenger share:** a location's departing passenger segments divided by national departing passenger segments in the same year.
- **Source:** BTS T-100 Domestic Segment, scheduled passenger service (Class F), calendar years 2015–2025.

</div>

```js
import * as d3 from "npm:d3";

// Place both processed files in src/data/. These are the outputs from the Q2 pipeline.
const nationalRaw = await FileAttachment("./data/q2_national_year_F.csv").csv({typed: true});
const airportRaw = await FileAttachment("./data/q2_airport_year_F.csv").csv({typed: true});
const fields = [
  {key: "passengers", label: "Passengers", color: "#2563eb"},
  {key: "seats", label: "Available seats", color: "#d97706"},
  {key: "departures_performed", label: "Performed departures", color: "#0d9488"}
];
const fmt = d3.format(",.0f");
const pct = d3.format("+.1f");
const years = d3.range(2015, 2026);
const national = nationalRaw.map(d => ({...d, year: +d.year})).sort((a, b) => a.year - b.year);
const airportData = airportRaw.map(d => ({...d, year: +d.year, airport: String(d.airport ?? d.airport_code ?? d.origin ?? d.airport_id ?? ""), state: String(d.state ?? "").trim()}));
const baseNational = national.find(d => d.year === 2019);
function index(value, base) { return Number.isFinite(+value) && Number.isFinite(+base) && +base > 0 ? 100 * +value / +base : null; }
function sumRows(rows, field) { return d3.sum(rows, d => +d[field] || 0); }
function lineChart(lines, options = {}) {
  const w = 1050, h = options.height ?? 310;
  const margin = {top: 22, right: 28, bottom: 47, left: 58};
  const all = lines.flatMap(s => s.values.filter(v => Number.isFinite(v.value)));
  const max = d3.max(all, d => d.value) ?? 110;
  const y = d3.scaleLinear().domain([0, Math.max(110, max * 1.1)]).nice().range([h - margin.bottom, margin.top]);
  const x = d3.scaleLinear().domain([2015, 2025]).range([margin.left, w - margin.right]);
  const div = document.createElement("div"); div.className = "q2-chart";
  const tip = document.createElement("div"); tip.className = "q2-tip";
  const svg = d3.create("svg").attr("viewBox", `0 0 ${w} ${h}`);
  svg.append("g").attr("transform", `translate(0,${h-margin.bottom})`).call(d3.axisBottom(x).ticks(11).tickFormat(d3.format("d")));
  svg.append("g").attr("transform", `translate(${margin.left},0)`).call(d3.axisLeft(y).ticks(6).tickFormat(d => `${d}`));
  svg.append("g").selectAll("line").data(y.ticks(6)).join("line")
    .attr("x1", margin.left).attr("x2", w - margin.right)
    .attr("y1", y).attr("y2", y).attr("stroke", "currentColor").attr("opacity", .12);
  svg.append("line").attr("x1", margin.left).attr("x2", w - margin.right)
    .attr("y1", y(100)).attr("y2", y(100)).attr("stroke", "currentColor")
    .attr("stroke-dasharray", "4,4").attr("opacity", .5);
  svg.append("text").attr("x", margin.left + 7).attr("y", y(100) - 5)
    .attr("font-size", 12).attr("fill", "currentColor").text("2019 baseline = 100");
  const path = d3.line().defined(d => Number.isFinite(d.value)).x(d => x(d.year)).y(d => y(d.value));
  lines.forEach((series, j) => {
    svg.append("path").datum(series.values).attr("d", path).attr("fill", "none")
      .attr("stroke", series.color).attr("stroke-width", 2.8);
    svg.append("g").selectAll("circle").data(series.values.filter(d => Number.isFinite(d.value)))
      .join("circle").attr("cx", d => x(d.year)).attr("cy", d => y(d.value))
      .attr("r", 4).attr("fill", series.color).attr("stroke", "var(--theme-background,white)")
      .attr("stroke-width", 1.2).style("cursor", "crosshair")
      .on("pointerenter pointermove", (event, d) => {
        tip.textContent = `${series.label} · ${d.year}: ${d.value.toFixed(1)} (2019=100)${Number.isFinite(d.actual) ? ` · ${fmt(d.actual)} actual` : ""}`;
        tip.style.display = "block";
        const r = div.getBoundingClientRect();
        tip.style.left = `${Math.max(0, Math.min(r.width - tip.offsetWidth, event.clientX - r.left + 12))}px`;
        tip.style.top = `${Math.max(0, event.clientY - r.top - tip.offsetHeight - 8)}px`;
      }).on("pointerleave", () => { tip.style.display = "none"; });
  });
  div.append(svg.node(), tip);
  const legend = document.createElement("div"); legend.className = "q2-legend";
  for (const s of lines) {
    const label = document.createElement("span"); label.className = "q2-key";
    const mark = document.createElement("i"); mark.style.background = s.color;
    label.append(mark, document.createTextNode(s.label)); legend.append(label);
  }
  const out = document.createElement("div"); out.append(div, legend); return out;
}
```

## National traffic and capacity, 2015–2025

The three lines compare national annual passenger segments, available seats, and performed departures, each divided by its own 2019 value. This reveals whether passenger activity, seating capacity, and flight frequency recovered at the same pace.

The next chart compares passenger traffic recovery across selected states or departure airports. Each line uses **that location's own 2019 passenger total** as its baseline, rather than the national total.

```js
// Read the radio value in a different block so Framework reacts to changes.
const level = geographicLevel === "Airport" ? "Airport" : "State";
const groupedData = Array.from(d3.group(airportData.filter(d => level === "Airport" || d.state), d => level === "State" ? d.state : d.airport), ([code, rows]) => ({
  code, rows: d3.rollups(rows, vals => sumRows(vals, "passengers"), d => d.year).map(([year, passengers]) => ({year, passengers})).sort((a, b) => a.year - b.year)

const eligible = groupedData.filter(g => (g.rows.find(d => d.year === 2019)?.passengers ?? 0) > 0)
  .sort((a, b) => d3.descending(a.rows.find(d => d.year === 2019)?.passengers ?? 0, b.rows.find(d => d.year === 2019)?.passengers ?? 0));
const regionChoice = view(Inputs.select(eligible.map(d => d.code), {label: `Choose ${level.toLowerCase()}`, multiple: true, value: eligible.slice(0, 5).map(d => d.code)}));
```

## How the data was prepared

The project's Q2 pipeline uses BTS T-100 Domestic Segment records for **scheduled passenger service (Class F)**. It aggregates passengers, available seats, and performed departures by year nationally and by departure airport and year. State totals are obtained by summing the airport records within each state. Each national, state, or airport recovery series is divided by its own 2019 total and multiplied by 100. State and airport shares divide the selected location's passenger segments by the national passenger-segment total for the same year.

The processed inputs are `q2_national_year_F.csv` and `q2_airport_year_F.csv`. Zero or missing 2019 denominators are not assigned recovery indices; locations lacking a comparable baseline are omitted from the recovery selector.
