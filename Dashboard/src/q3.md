# Q3: Domestic Aviation Activity vs. State Population

**Research question:** How does US domestic departing passenger activity compare with state population, and does Georgia stand out?

This page compares the number of **departing passenger segments per resident** in each state, using a map and a ranked bar chart. Select a year from 2015 to 2025 and click a state to inspect its values.

<div class="note" label="Definitions and source">

- **Departing passenger segment:** One passenger carried on a nonstop domestic flight segment departing an airport in the state. Connecting passengers may be counted on multiple segments.
- **Passengers per resident:** Departing passenger segments from airports in a state divided by that state's annual population. This does **not** measure the percentage of residents who flew.
- **Geographic scope:** The 50 states and Washington, D.C.; territories are excluded because their population estimates are not part of this comparison.
- **Source:** BTS T-100 Domestic Segment, scheduled passenger service (Class F), and U.S. Census annual state population estimates, 2015–2025.

</div>

```js
import * as d3 from "npm:d3";
import {feature} from "npm:topojson-client@3";

const records = await FileAttachment("./data/q3_state_year.csv").csv({typed: true});
// Public US Atlas boundary file. Requires internet access in the viewer's browser.
const atlas = await d3.json("https://cdn.jsdelivr.net/npm/us-atlas@3/states-10m.json");

const fipsToCode = {
  "01":"AL","02":"AK","04":"AZ","05":"AR","06":"CA","08":"CO",
  "09":"CT","10":"DE","11":"DC","12":"FL","13":"GA","15":"HI",
  "16":"ID","17":"IL","18":"IN","19":"IA","20":"KS","21":"KY",
  "22":"LA","23":"ME","24":"MD","25":"MA","26":"MI","27":"MN",
  "28":"MS","29":"MO","30":"MT","31":"NE","32":"NV","33":"NH",
  "34":"NJ","35":"NM","36":"NY","37":"NC","38":"ND","39":"OH",
  "40":"OK","41":"OR","42":"PA","44":"RI","45":"SC","46":"SD",
  "47":"TN","48":"TX","49":"UT","50":"VT","51":"VA","53":"WA",
  "54":"WV","55":"WI","56":"WY"
};

const stateFeatures = feature(atlas, atlas.objects.states).features
  .map(d => ({...d, code: fipsToCode[String(d.id).padStart(2, "0")]}))
  .filter(d => d.code);

const stateNames = new Map(stateFeatures.map(d => [d.code, d.properties.name]));
const years = [...new Set(records.map(d => +d.year).filter(Number.isFinite))].sort((a,b) => a-b);
const validStates = new Set(Object.values(fipsToCode));

// Normalize numerical columns and respect the documented 50 states + DC scope.
const stateRows = records
  .map(d => ({
    ...d,
    year: +d.year,
    state: String(d.state || "").trim().toUpperCase(),
    passengers: d.passengers === "" || d.passengers == null ? NaN : +d.passengers,
    population: d.population === "" || d.population == null ? NaN : +d.population
  }))
  .filter(d => validStates.has(d.state));

const numberFormat = d3.format(",.0f");
const rateFormat = d3.format(".2f");
```

## Passenger activity relative to state population

The map and bar chart compare **the same ratio** for every state in the selected year. Darker states and longer bars represent more departing passenger segments per resident, not a higher share of residents who flew.

```js
const topState = [...annual].sort((a, b) => d3.descending(a.rate, b.rate))[0];
const georgia = stateByCode.get("GA");
const gaRank = georgia ? 1 + annual.filter(d => d.rate > georgia.rate).length : null;
const usRatio = d3.sum(annual, d => d.passengers) / d3.sum(annual, d => d.population);

### Map: Passenger segments per resident

Click any state to select it; the bar chart and details section update together. Alaska and Hawaii are shown using the Albers USA projection's insets.

const mapWidth = 920;
const mapHeight = 590;
const projection = d3.geoAlbersUsa().fitSize([mapWidth - 20, mapHeight - 30], {

const mapTip = document.createElement("div");
Object.assign(mapTip.style, {
  position: "absolute", pointerEvents: "none", display: "none",
  background: "#172338", color: "white", borderRadius: "8px",
  padding: "10px 12px", fontSize: "12px", lineHeight: "1.5",

function placeMapTip(event) {
  const rect = mapWrap.getBoundingClientRect();
  const x = event.clientX - rect.left;
  const y = event.clientY - rect.top;
  const tipW = mapTip.offsetWidth || 180;
  const left = Math.max(0, Math.min(rect.width - tipW, x + 12));
  mapTip.style.left = `${left}px`;
  mapTip.style.top = `${Math.max(0, y - 18)}px`;
}

mapSvg.append("g")
  .selectAll("path")
  .data(stateFeatures)
  .join("path")
  .attr("d", path)
  .attr("fill", d => {
    const item = stateByCode.get(d.code);
    return item ? color(item.rate) : "#e5e7eb";
  })
  .attr("stroke", d => d.code === selectedState ? "#d9480f" : "#ffffff")
  .attr("stroke-width", d => d.code === selectedState ? 3 : 1)
  .attr("cursor", "pointer")
  .attr("tabindex", 0)
  .attr("role", "button")
  .attr("aria-label", d => `Select ${d.properties.name}`)
  .on("click", (event, d) => chooseState(d.code))
  .on("keydown", (event, d) => {
    if (event.key === "Enter" || event.key === " ") {
      event.preventDefault(); chooseState(d.code);
    }
  })
  .on("pointerenter pointermove", (event, d) => {
    const item = stateByCode.get(d.code);
    mapTip.innerHTML = "";
    const lines = [d.properties.name,
      item ? `${rateFormat(item.rate)} segments / resident` : "No comparable data",
      item ? `Passengers: ${numberFormat(item.passengers)}` : "",
      item ? `Population: ${numberFormat(item.population)}` : ""
    ].filter(Boolean);
    for (const line of lines) {
      const div = document.createElement("div");
      div.textContent = line;
      mapTip.append(div);
    }
    mapTip.style.display = "block";
    placeMapTip(event);
  })
  .on("pointerleave", () => { mapTip.style.display = "none"; });

mapWrap.append(mapSvg.node(), mapTip);
display(mapWrap);
```

## How the data was prepared

BTS T-100 domestic scheduled passenger-service (Class F) departures were grouped by **origin state and year**. Departing passenger segments were summed across airports in each state and joined to same-year U.S. Census population figures. The calculation shown in both charts is:

`Passengers per resident = State departing passenger segments / State population`

The processed file is `q3_state_year.csv`. Records with missing passenger totals, missing population, or nonpositive population are not plotted. The map and ranked bars use the same selected-year data and preserve state values when a different state is highlighted.
